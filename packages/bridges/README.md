# @kernlize/bridges

Locator parsing, bridge contract, registry and HTTP bridge with SSRF policy for the kernl shell.

| Registry | Package |
| --- | --- |
| npm | `@kernlize/bridges` |
| JSR | `@kernl/bridges` |

```sh
npm install @kernlize/bridges
# or, with Deno
deno add jsr:@kernl/bridges
```
