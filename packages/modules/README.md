# @kernlize/modules

kernl's modules over the kernel: every opinion a host can name, each its own module (D-068).

| Registry | Package |
| --- | --- |
| npm | `@kernlize/modules` |
| JSR | `@kernl/modules` |

```sh
npm install @kernlize/modules
# or, with Deno
deno add jsr:@kernl/modules
```
