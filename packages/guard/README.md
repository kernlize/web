# @kernlize/guard

Ingress flood control, visibility gating, focus-aware firewall and CSP profile for the kernl shell.

| Registry | Package |
| --- | --- |
| npm | `@kernlize/guard` |
| JSR | `@kernl/guard` |

```sh
npm install @kernlize/guard
# or, with Deno
deno add jsr:@kernl/guard
```
