# @kernlize/messaging

Messaging provider contract, registry and composite direct-message adapter for the kernl shell.

| Registry | Package |
| --- | --- |
| npm | `@kernlize/messaging` |
| JSR | `@kernl/messaging` |

```sh
npm install @kernlize/messaging
# or, with Deno
deno add jsr:@kernl/messaging
```
