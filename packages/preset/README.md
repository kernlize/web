# @kernlize/preset

kernl's preset: the module list kernl.run runs over the kernel, and createKernl (D-068).

| Registry | Package |
| --- | --- |
| npm | `@kernlize/preset` |
| JSR | `@kernl/preset` |

```sh
npm install @kernlize/preset
# or, with Deno
deno add jsr:@kernl/preset
```
