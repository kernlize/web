# @kernlize/kernel

kernl's floor: applet resolve, plan and mount, the guard pipeline, the firewall, grants, signing consent, secrets, the media player, the module host and the ask channel. Every opinion is a module a host names (D-068).

| Registry | Package |
| --- | --- |
| npm | `@kernlize/kernel` |
| JSR | `@kernl/kernel` |

```sh
npm install @kernlize/kernel
# or, with Deno
deno add jsr:@kernl/kernel
```
