# @kernlize/ui-model

Framework-free view models for a kernl shell: the grants list, ask queues and logs, as rxjs streams.

| Registry | Package |
| --- | --- |
| npm | `@kernlize/ui-model` |
| JSR | `@kernl/ui-model` |

```sh
npm install @kernlize/ui-model
# or, with Deno
deno add jsr:@kernl/ui-model
```
