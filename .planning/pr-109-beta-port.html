Notes
Profiles
Notes in front · Profiles still mounted.

On a narrow screen the shell gives every window the whole desk, so the front one is all you see.

Background delivery: this example uses an already-connected handler. A fresh handler opened behind the current window may need to be shown before it can connect; if delivery times out, the shell asks you to show it and retry rather than switching automatically.

What makes the port safe to use

Verified identity

Lookups accept only manifests matching the requested event ID or applet coordinate. Recent preserves an exact-event link rather than converting it to a moving release address. Stack listings share the shell’s event store and use the optional cache for offline reads.

Grants survive the right window

A running window is reused only when the same verified artifact started with compatible permissions. If it needs replacing, temporary grant changes stay in force through the mount and are cleared when no window needs them.

Mount and route reliably

Each new member mounts before the next is admitted, so opening a large stack cannot evict its own waiting plans. Failures are counted without stopping the rest. Intent retries skip windows that lack the receiving domain or convention and keep the recipient checks.

Unchanged: the original beta branch, upstream’s theme broadcasting, and upstream’s typed consent questions are not replaced by this PR. There’s no new dependency or lockfile change in the submitted diff.

What was verified

  • 3,638 tests passed with 100% coverage. Package smoke checks covered eight tarballs and 40 entry points.
  • 66 targeted browser tests passed across Chromium and Firefox. The full browser suite and JSR dry run were not run locally.
